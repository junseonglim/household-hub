# 06. 로드맵 · 결정 사항

> 상태: v0.3 · 2026-10-11

## 1. 마일스톤

순서 이유: **청소가 core 할 일 엔진(반복 규칙 · 담당자 · 완료 기록)을 처음 만드는 모듈**이라 먼저 하고, 요리는 그 패턴을 재사용한다. 배포는 M1부터 바로 해서 가족이 일찍 써 볼 수 있게 한다.

`(직접)` 표시는 계정 생성처럼 직접 하셔야 하는 작업입니다.

### M0. 프로젝트 기반

- [ ] GitHub 비공개 저장소 생성 `(직접)` — 로컬 git 저장소는 준비됨
- [x] Next.js 16 + TypeScript(strict) + pnpm 프로젝트 생성
- [x] Tailwind CSS 4 + shadcn/ui, 기본 레이아웃 (모바일 하단 탭 / PC 사이드바: 청소 · 요리 · 육아 · 설정), 다크 모드
- [x] 육아 탭은 "준비 중" 빈 화면 + 모듈 폴더(README)
- [x] Drizzle 설정 · 첫 마이그레이션 생성 (`household` 테이블), `/api/health`
- [x] Docker로 로컬 PostgreSQL 실행 · 마이그레이션 적용
- [x] ESLint(모듈 간 import 금지 규칙 포함), Prettier, Vitest, Playwright 설정

**완료 기준**: `pnpm dev`로 탭 4개짜리 레이아웃이 뜨고 DB 연결이 확인된다.
→ 2026-10-04 완료 (E2E 8개 통과: 휴대폰 · PC × 화면 이동 · DB 연결). GitHub 저장소 생성만 M1 배포 전에 진행.

- [x] 설정: 내 정보, 비밀번호 변경, 구성원 관리, 가입 승인 · 거절, 비밀번호 초기화, 비상 초기화 스크립트

- [x] GitHub · Vercel · Neon 가입 및 연결, 첫 배포 → [배포 가이드](deploy.md) (2026-10-04, `/api/health` 정상, owner 가입 완료)

**완료 기준**: 운영 주소에서 내가 가입(owner) → 배우자가 가입 → 내가 승인 → 배우자 접속 성공.
