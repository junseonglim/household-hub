# 모듈: 청소

> 상태: 초안 v0.1 · 2026-10-03 · 사용 테이블: space, task(`module = 'cleaning'`), task_completion

## 1. 목표

반복되는 청소 · 정리 일을 한 번 등록해 두면 시스템이 다음 차례를 기억하고, 가족 누구나 오늘 할 일을 보고 한 번 탭으로 완료한다. "그거 마지막으로 언제 했지?"라는 질문을 없앤다.

청소 모듈은 core **할 일 엔진의 첫 사용처**다. 자체 테이블 없이 공간 · 할 일 · 완료 기록 위에 화면과 규칙을 얹는다. 빨래 · 설거지 · 쓰레기 같은 생활 정리 일도 이 모듈에서 다룬다.

## 2. 사용자 스토리

- 관리자로서, 반복 청소 일을 한 번 등록해 두고 다시 신경 쓰고 싶지 않다.
- 구성원으로서, 오늘 해야 할 청소와 밀린 청소를 한눈에 보고 싶다.
- 구성원으로서, 청소를 마치면 한 번 탭으로 완료하고, 잘못 눌렀으면 바로 취소하고 싶다.
- 구성원으로서, 배우자가 한 일을 대신 체크해 주고 싶다.
- 가족으로서, 이불 빨래를 마지막으로 언제 했는지 알고 싶다.
- 가족으로서, 누가 얼마나 했는지 공정하게 보고 싶다 (→ 대시보드).

## 3. 기능

### MVP

| 기능 | 내용 |
|---|---|
| 공간 관리 | 기본 공간 자동 생성, 추가 · 이름 변경 · 순서 변경 · 보관 |
| 할 일 등록 | 제목, 공간, 반복 규칙, 시작일, 담당자(누구나 / 특정 구성원), 예상 소요 시간, 메모 |
| 오늘 보기 | 밀린 일 / 오늘 / 이번 주 예정을 묶어 표시, '내 담당' 필터 |
| 완료 | 1탭 완료, 완료자 · 완료 시각 변경, 메모 |
| 완료 취소 | 가장 최근 완료 1건 |
| 공간별 보기 | 공간마다 할 일 수, 밀린 일 수, 가장 오래 안 한 일 |
| 기록 | 할 일별 완료 내역 (누가, 언제) |
| 처음 설정 | 추천 청소 항목을 골라 한 번에 등록 |

### 이후

- 담당 순번 로테이션 (완료할 때마다 다음 사람에게)
- 격주 반복 (예: 격주 토요일)
- 하위 체크리스트 (욕실 청소 = 변기 · 세면대 · 배수구)
- 미루기 (오늘 못 하면 내일로)
- 알림, 완료 사진

## 4. 화면

### 4.1 할 일 — `/cleaning`

```
청소                         [전체 | 내 담당]

밀린 일 (2)
 ○ 화장실 청소   🛁 욕실   3일 지남    [아빠]
 ○ 이불 빨래     🛏️ 침실   1일 지남    누구나

오늘 (2)
 ○ 설거지        🍳 주방   매일        [엄마]
 ○ 분리수거      🪴 베란다 매주 화·금   누구나

이번 주
 ○ 냉장고 정리   🍳 주방   10/8 (목)

                                      [+ 할 일]
```

- 왼쪽 ○를 누르면 즉시 완료 → 토스트 "완료! 다음: 10/17 (토)" + **[취소]** (5초).
- 행을 길게 누르거나 ⋯ 메뉴: 다른 사람이 한 것으로 기록, 완료 시각 변경, 메모 추가.
- 행을 누르면 상세 화면.

### 4.2 공간별 — `/cleaning/spaces`

공간 카드 목록. 카드마다 할 일 수, 밀린 일 수, "가장 오래 안 한 일: 화장실 청소 · 9일 전". 카드를 누르면 그 공간의 할 일 목록.

### 4.3 할 일 등록 · 수정 — `/cleaning/tasks/new`, `/cleaning/tasks/[id]`

| 입력 | 형태 |
|---|---|
| 제목 * | 텍스트 |
| 공간 | 선택 (이모지 칩) |
| 반복 | 한 번만 / 매일 / 매주(요일 다중 선택) / 매월(날짜) / N일마다 |
| 시작일 | 날짜, 기본 오늘 |
| 담당자 | 누구나 / 구성원 선택 |
| 예상 소요 시간 | 분 (선택) |
| 메모 | 텍스트 (선택) |

반복 선택 아래에 미리보기를 보여 준다: "다음 예정일: 10/10 (토), 10/17 (토), 10/24 (토)".
상세 화면 아래에는 완료 기록 목록과 [보관] 버튼.

### 4.4 처음 설정 — `/cleaning/setup`

첫 가입으로 가구가 만들어진 직후, 또는 할 일이 하나도 없을 때 안내한다. 추천 항목을 체크하고 반복 규칙 · 공간을 고쳐서 한 번에 등록한다.

| 할 일 | 공간 | 기본 반복 |
|---|---|---|
| 청소기 돌리기 | 거실 | 2일마다 |
| 바닥 물걸레 | 거실 | 매주 수 · 토 |
| 설거지 · 싱크대 정리 | 주방 | 매일 |
| 음식물 쓰레기 버리기 | 주방 | 2일마다 |
| 분리수거 | 베란다 | 매주 (지역 배출 요일 선택) |
| 화장실 청소 | 욕실 | 매주 토 |
| 수건 빨래 | 다용도실 | 3일마다 |
| 이불 빨래 | 침실 | 14일마다 |
| 냉장고 정리 | 주방 | 매월 1일 |
| 세탁기 통세척 | 다용도실 | 30일마다 |
| 에어컨 · 공기청정기 필터 | 거실 | 90일마다 |
| 현관 정리 | 현관 | 매주 일 |

템플릿은 DB가 아니라 코드 상수로 둔다.

## 5. 규칙

- **다음 예정일 계산 · 상태 분류**는 [03. 아키텍처](../03-architecture.md) 6.1절을 따른다.
- **완료자**는 기본이 '나'이고, 다른 구성원으로 바꿀 수 있다. 담당자가 아니어도 누구나 완료할 수 있다 (담당자는 표시용).
- **완료 시각**은 기본이 지금이고, 과거로 바꿀 수 있다 (어제 한 일을 오늘 체크). 다음 예정일은 바꾼 날짜 기준으로 계산한다. 미래 시각은 허용하지 않는다.
- **완료 취소**는 가장 최근 완료 1건만 가능하다. 취소하면 `next_due_date`는 그 완료 기록의 `due_date`로, `last_completed_at`은 직전 완료 기록의 시각으로 되돌린다.
- **반복 규칙을 바꾸면** 오늘을 시작일로 삼아 `next_due_date`를 다시 계산한다.
- **1회성 할 일**을 완료하면 '완료됨'으로 옮기고, 최근 7일 것만 목록 아래에 접어서 보여 준다.
- **보관**한 할 일은 목록에서 사라지지만 완료 기록은 남는다.

## 6. 활동 로그

| action | 언제 | payload |
|---|---|---|
| `task.created` | 할 일 등록 (템플릿 일괄 등록은 1건으로) | title, spaceName / count |
| `task.completed` | 완료 | title, completedByName, dueDate, completedOn |
| `task.completion_undone` | 완료 취소 | title |
| `task.archived` | 보관 | title |

## 7. 대시보드에서 보여 줄 수 있는 것 (참고)

- 밀린 일 수의 추이
- 공간별 마지막 청소 후 경과일
