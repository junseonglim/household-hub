# 모듈: 청소

> 상태: v0.2 (M2 구현 반영) · 2026-10-11 · 사용 테이블: space, task(`module = 'cleaning'`), task_completion

## 1. 목표

반복되는 청소 · 정리 일을 한 번 등록해 두면 시스템이 다음 차례를 기억하고, 가족 누구나 오늘 할 일을 보고 한 번 탭으로 완료한다. "그거 마지막으로 언제 했지?"라는 질문을 없앤다.

청소 모듈은 core **할 일 엔진의 첫 사용처**다. 자체 테이블 없이 공간 · 할 일 · 완료 기록 위에 화면과 규칙을 얹는다. 빨래 · 설거지 · 쓰레기 같은 생활 정리 일도 이 모듈에서 다룬다.

## 2. 사용자 스토리

- 관리자로서, 반복 청소 일을 한 번 등록해 두고 다시 신경 쓰고 싶지 않다.
- 구성원으로서, 오늘 해야 할 청소와 밀린 청소를 한눈에 보고 싶다.
- 구성원으로서, 청소를 마치면 한 번 탭으로 완료하고, 잘못 눌렀으면 바로 취소하고 싶다.
- 구성원으로서, 배우자가 한 일을 대신 체크해 주고 싶다.
- 가족으로서, 이불 빨래를 마지막으로 언제 했는지 알고 싶다.
- 가족으로서, 누가 얼마나 했는지 공정하게 보고 싶다 (→ 대시보드).

## 3. 기능

### MVP

| 기능 | 내용 |
|---|---|
| 공간 관리 | 기본 공간 자동 생성. 관리자는 추가 · 이름 · 아이콘 변경 · 순서 변경 · 보관 |
| 할 일 등록 | 제목, 공간, 반복 규칙, 시작일, 담당자(누구나 / 특정 구성원), 예상 소요 시간, 메모 |
| 오늘 보기 | 밀린 일 / 오늘 / 이번 주 / 기한 없음을 묶어 표시 (나중에 · 완료됨은 접어 둠), '내 담당' 필터 |
| 완료 | 1탭 완료, '자세히 기록'으로 완료자 · 완료 시각 변경, 메모 |
| 완료 취소 | 가장 최근 완료 1건 |
| 공간별 보기 | 공간마다 할 일 수, 밀린 일 수, 가장 오래 안 한 일 |
| 기록 | 할 일별 완료 내역 (누가, 언제) |
| 처음 설정 | 추천 청소 항목을 골라 한 번에 등록 |

### 이후

- 담당 순번 로테이션 (완료할 때마다 다음 사람에게)
- 격주 반복 (예: 격주 토요일)
- 하위 체크리스트 (욕실 청소 = 변기 · 세면대 · 배수구)
- 미루기 (오늘 못 하면 내일로)
- 보관한 할 일 되살리기
- 알림, 완료 사진

## 4. 화면

### 4.1 할 일 — `/cleaning`

```
청소                         [전체 | 내 담당]

밀린 일 (2)
 ○ 화장실 청소   🛁 욕실   3일 지남    [아빠]
 ○ 이불 빨래     🛏️ 침실   1일 지남    누구나

오늘 (2)
 ○ 설거지        🍳 주방   매일        [엄마]
 ○ 분리수거      🪴 베란다 매주 화·금   누구나

이번 주
 ○ 냉장고 정리   🍳 주방   10/8 (목)

                                      [+ 할 일]
```

- 왼쪽 ○를 누르면 즉시 완료(서버 응답 전에 완료 표시) → 토스트 "완료! 다음: 내일" 또는 "완료! 다음: 10/17 (토)" + **[취소]** (6초).
- ⋯ 버튼 = **자세히 기록** 창: 한 사람(다른 가족으로 바꾸기), 완료 시각(과거로만), 메모.
- 행을 누르면 상세 화면.
- **내 담당** (`/cleaning?view=mine`): 나에게 맡겨진 일 + 누구나 할 수 있는 일.
- **나중에**(7일 뒤부터)와 **완료됨**(끝낸 1회성, 최근 7일)은 접어 둔다.
- 할 일이 하나도 없으면 **추천 할 일 고르기**(처음 설정)로 안내한다.

### 4.2 공간별 — `/cleaning/spaces`

공간 카드 목록. 카드마다 할 일 수, 밀린 일 수, "가장 오래 안 한 일: 화장실 청소 · 9일 전"(한 번도 안 한 일이 먼저, '기록 없음'). 공간이 없는 할 일이 있으면 '공간 없음' 카드를 마지막에 둔다.

- 카드를 누르면 그 공간의 할 일 목록 — `/cleaning/spaces/[id]` (`none` = 공간 없음). 여기서 [할 일 추가]를 누르면 공간이 미리 골라진다.
- 관리자에게만 **공간 편집** — `/cleaning/spaces/manage`: 추가, 이름 · 아이콘(이모지), 위 · 아래로 순서, 보관.

### 4.3 할 일 등록 · 상세 · 수정 — `/cleaning/tasks/new`, `/cleaning/tasks/[id]`, `/cleaning/tasks/[id]/edit`

| 입력 | 형태 |
|---|---|
| 제목 * | 텍스트 |
| 공간 | 선택 (이모지 칩) |
| 반복 | 한 번만(기한 선택) / 매일 / 매주(요일 다중 선택, 기본: 오늘 요일) / 매월(날짜, 31 = 말일) / N일마다 |
| 시작일 | 날짜, 기본 오늘 (한 번만이면 없음) |
| 담당자 | 누구나 / 구성원 선택 |
| 예상 소요 시간 | 분 (선택) |
| 메모 | 텍스트 (선택) |

반복 선택 아래에 미리보기를 보여 준다: "다음 예정일: 10/10 (토), 10/17 (토), 10/24 (토)". 수정 화면의 미리보기는 저장할 때와 같은 규칙(5절)으로 계산한다.

상세 화면: 요약(다음 예정 · 반복 · 공간 · 담당 · 마지막으로 한 날 · 메모), [완료] [자세히 기록], 완료 기록 목록과 [마지막 완료 취소], 맨 아래 [이 할 일 보관](보관 권한이 있을 때만).

### 4.4 처음 설정 — `/cleaning/setup`

할 일이 하나도 없으면 청소 화면에서 안내하고, 목록 아래 '추천 할 일 더 고르기'로 언제든 다시 들어올 수 있다. 추천 항목을 체크하고 '반복 · 공간 바꾸기'를 펼쳐 고친 뒤 한 번에 등록한다. 모두 오늘부터 시작한다. 같은 제목의 할 일이 이미 있으면 '이미 있음'으로 표시하고 기본 선택을 풀어 둔다.

| 할 일 | 공간 | 기본 반복 |
|---|---|---|
| 청소기 돌리기 | 거실 | 2일마다 |
| 바닥 물걸레 | 거실 | 매주 수 · 토 |
| 설거지 · 싱크대 정리 | 주방 | 매일 |
| 음식물 쓰레기 버리기 | 주방 | 2일마다 |
| 분리수거 | 베란다 | 7일마다 (배출 요일이 정해져 있으면 매주 요일로 바꾸기) |
| 화장실 청소 | 욕실 | 매주 토 |
| 빨래 돌리기 · 널기 | 다용도실 | 2일마다 |
| 수건 빨래 | 다용도실 | 3일마다 |
| 이불 빨래 | 침실 | 14일마다 |
| 냉장고 정리 | 주방 | 매월 1일 |
| 세탁기 통세척 | 다용도실 | 30일마다 |
| 에어컨 · 공기청정기 필터 | 거실 | 90일마다 |
| 현관 정리 | 현관 | 매주 일 |

템플릿은 DB가 아니라 코드 상수로 둔다 (`src/modules/cleaning/templates.ts`). 공간은 이름으로 찾고, 없으면 '공간 없음'으로 등록한다.

## 5. 규칙

- **다음 예정일 계산 · 상태 분류**는 [03. 아키텍처](../03-architecture.md) 6.1절을 따른다.
- **완료자**는 기본이 '나'이고, 다른 구성원으로 바꿀 수 있다. 담당자가 아니어도 누구나 완료할 수 있다 (담당자는 표시용).
- **완료 시각**은 기본이 지금이고, 과거로 바꿀 수 있다 (어제 한 일을 오늘 체크). 다음 예정일은 바꾼 날짜 기준으로 계산한다. 미래 시각은 허용하지 않는다.
  - 마지막 완료보다 이전 시각으로 기록하면 기록만 남고, 다음 예정일은 뒤로 돌아가지 않는다.
- **동시에 완료**: 화면에 보였던 예정일과 지금 예정일이 다르면(다른 가족이 먼저 완료) 기록하지 않고 "다른 가족이 먼저 완료했어요"를 알린 뒤 목록을 새로 그린다. 같은 할 일을 두 사람이 동시에 눌러도 한 번만 넘어간다.
- **완료 취소**는 가장 최근에 기록한 완료 1건만 가능하다 (토스트의 [취소], 상세 화면의 [마지막 완료 취소]). 취소하면 `next_due_date`는 그 완료 기록의 `due_date`로, `last_completed_at`은 남은 기록 중 가장 늦은 시각으로 되돌린다.
- **수정**(`scheduleAfterEdit`):
  - 시작일을 바꾸면 그날부터 `next_due_date`를 다시 계산한다.
  - 반복 규칙만 바꾸면 오늘(시작일이 아직 안 왔으면 시작일)부터 다시 계산한다. N일마다는 마지막으로 한 날이 있으면 그날부터 센다.
  - 둘 다 그대로면 `next_due_date`를 건드리지 않는다.
- **1회성 할 일**을 완료하면 '완료됨'으로 옮기고, 최근 7일 것만 목록 아래에 접어서 보여 준다.
- **보관**한 할 일은 목록에서 사라지지만 완료 기록은 남는다. 보관 권한: 관리자 이상, 또는 내가 만든 할 일. 되살리는 화면은 이후에 만든다.
- **공간을 보관**하면 그 공간의 할 일은 '공간 없음'으로 옮긴다. 이름이 같은 공간은 둘 만들 수 없다.
- **구성원을 내보내면** 그 사람이 맡던 할 일은 '누구나'로 돌린다.

## 6. 활동 로그

| action | 언제 | payload |
|---|---|---|
| `task.created` | 할 일 등록 (템플릿 일괄 등록은 1건으로) | title, spaceName / count |
| `task.completed` | 완료 | title, completedByName, dueDate, completedOn |
| `task.completion_undone` | 완료 취소 | title |
| `task.archived` | 보관 | title |
